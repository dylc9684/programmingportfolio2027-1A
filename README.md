# programmingportfoliocalculator

## Overview
This is a calculator that contains all the digits alongside simple operations. It also contains special operations and a display.

## Current Status
Working:
- Basic layout with number buttons
- Display screen for input and results

Still in progress:
- Keyboard input=

## How to Run
Built with Processing.
Processing version: 4.3

Open the `Calculator` folder in Processing and run the main `.pde` file.

## Controls
Mouse:
- Click on the numbered buttons and operation buttons to input calculations.

Keyboard:
- Keyboard inputs are currently not yet implemented.
